# CDNet
A collaboration and disentanglement network for cross-domain joint grading of Diabetic Retinopathy and Diabetic Macular Edema

## Data collection
* The three datasets we used can be downloaded via: IDRID: [https://ieee-dataport.org/open-access/indian-diabetic-retinopathy-image-dataset-IDRiD](https://ieee-dataport.org/open-access/indian-diabetic-retinopathy-image-dataset-IDRiD), Messier: [https://www.adcis.net/en/third-party/messidor/](https://www.adcis.net/en/third-party/messidor/), and APTOS [https://www.kaggle.com/competitions/aptos2019-blindness-detection/data](https://www.kaggle.com/competitions/aptos2019-blindness-detection/data)
